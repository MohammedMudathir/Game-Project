# Snowman Dodge

Branches fall down the tree — move the snowman from side to side to dodge them.
Every branch you dodge scores a point, and the game speeds up as you go.

## Run it

```
pip install pygame
python3 game.py
```

## Controls

| Key | Action |
| --- | --- |
| ← / A | Move left |
| → / D | Move right |
| Space | Start / play again |
| Esc | Quit |

Your best score is saved to `highscore.txt`.
